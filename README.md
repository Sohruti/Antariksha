# Antariksha

Antariksha is an immersive cinematic space exploration website. A single scroll takes the user on a journey outward through the cosmos: Earth → Moon → Solar System → Kuiper Belt → Oort Cloud → nearby stars → nebulae → Milky Way → nearby galaxies → clusters → superclusters → cosmic web → observable universe → Big Bang.

The experience blends realistic 3D scenes, semantic zoom, parallax depth, scroll-triggered camera motion, and scrollytelling to make the scale of the universe feel emotional, not just informative.

**Stack:** Next.js, React, TypeScript, TailwindCSS, React Three Fiber + Drei, GSAP, Lenis, Framer Motion, GLSL shaders, postprocessing.

**Run locally:**

```bash
npm install
npm run dev
```

Open http://localhost:3000.

**Inspiration:** Neal.fun (Size of Space), Scale of the Universe 2, NASA Eyes, Space Engine, Apple cinematic product pages.
